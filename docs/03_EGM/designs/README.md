# EGM Living Design Specifications

This directory holds living specifications drafted by the **Elephant** (deep-context session) using the `/egm-draft` workflow.

## Rules:
1. Every new specification must use the template defined in [01_EGM_Elephant_Goldfish_Model_Guide.md](../01_EGM_Elephant_Goldfish_Model_Guide.md).
2. The Elephant writes **zero code** until the spec is audited by zero-context **Goldfish** subagents and approved by a human architect.
3. Filename format: `SPEC-XXX_<short_name>.md`.
