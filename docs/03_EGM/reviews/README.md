# EGM Goldfish Review Audits & Findings

This directory holds the recorded audits produced by stateless, zero-context **Goldfish** subagents during `/egm-review`.

## Rules:
1. Reviews are generated by fresh subagents with **zero prior conversation history**.
2. Findings are categorized as `BLOCKER`, `CONCERN`, or `NIT`.
3. In accordance with Canon 02, only a human engineer may approve findings triage and authorize implementation handoff.
4. Filename format: `YYYY-MM-DD_REVIEW_SPEC-XXX.md`.
